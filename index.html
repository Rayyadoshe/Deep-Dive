What is happening?

1. The user creates a password.
2. A random salt is generated.
3. PBKDF2 processes the password and salt using SHA-256.
4. The application stores the salt and derived hash — not the password.
5. When the user logs in, the entered password is processed again with the stored salt.
6. The new result is compared with the stored hash.
